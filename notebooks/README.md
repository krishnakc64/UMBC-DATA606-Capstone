
This folder contains the Jupyter notebook used during the development of the customer segmentation and RFM analysis project using PySpark.

## Files Included

- Customer_Segmentation_Bigdata_PySpark.ipynb  
  - Main notebook containing data preprocessing, RFM calculation, feature engineering, clustering, customer segmentation, and analysis using PySpark.

---

## Notebook Contents

The notebook includes:

- Data loading and preprocessing
- Handling large-scale e-commerce transaction data
- Recency, Frequency, and Monetary (RFM) calculation
- Feature engineering
- Data visualization and analysis
- K-Means clustering
- Customer segmentation
- Model evaluation
- Cluster interpretation and insights

---

## Technologies Used

- Python
- PySpark
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Project Goal

The main objective of this notebook is to perform scalable customer segmentation on large transactional datasets using distributed computing with PySpark.

The analysis helps identify different customer groups such as:

- Loyal customers
- High-value customers
- At-risk customers
- Low-engagement customers
