# Customer Segmentation Dataset

## Overview

This repository contains the dataset files used for the customer segmentation and RFM analysis project.  
Due to GitHub file size limitations, the original large dataset was divided into multiple smaller CSV files and uploaded separately.

The dataset is used for performing:

- RFM (Recency, Frequency, Monetary) Analysis
- Customer Segmentation
- Clustering using Machine Learning
- Customer behavior analysis using PySpark
